One line, at most 160 characters, roasting the smart fridge — entered in the
[make.fun competition](https://make.fun/c/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9).

## The entry

> The ice maker sounds like it's chewing gravel at 3 a.m., then serves one cube, like a vending machine with stage fright.

120 characters. The program (`main.ts`, Node 22) writes the line to
`/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
